Um banco de dados, por definição, é um conjunto de tabelas, organizados e inter-relacionadas, que
podem ser criadas, alteradas ou deletadas, de acordo com necessidades específicas do banco, sendo
que essa tarefa é de responsabildiade dos SGBD's(Sistemas Gerenciadores de Banco de Dados), no
caso, esse repo faz o uso de MySQL, contendo códigos, para criação da base , construção de tabelas,
alteração dessas, assim como, criação de chaves primárias e estrangeiras, bem como, atualização
de informações e inserção de dados nas tuplas.
